# Pioneers Rooms + UV Proxy

## Setup on Replit

1. Import this repo to Replit
2. Make sure your `index.html` is inside the `public/` folder
3. Hit **Run** — it installs dependencies and starts the server

## File Structure
```
public/
  index.html     ← Your Pioneers Rooms HTML goes here
  proxy.html     ← The proxy browser page
uv/
  uv.config.js   ← UV config (auto-populated on first run)
server.js        ← Express + Bare server
package.json     ← Dependencies
```

## Usage
- Main site: `https://yourrepl.repl.co/`
- Proxy page: `https://yourrepl.repl.co/proxy`
